# Lalitha N — Code & Creativity Portfolio

A responsive React + Vite portfolio starter with a sunrise-inspired hero, scrapbook-style creative corner, illustrated avatar, skills, project cards, and contact section.

## Run locally

1. Install Node.js (LTS).
2. Open this folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL printed by Vite.

## Before publishing

- Replace `your.email@example.com` in `src/main.jsx` with your real portfolio email.
- Update the GitHub and LinkedIn links to your profiles.
- Verify each skill reflects your current experience.
- Add real GitHub links, screenshots, and project-specific details to the project cards.
- Replace the illustrative scrapbook placeholders with your own photographs and craft images if you wish.
- Clearly mark any project that is still in progress.

## Build for deployment

Run `npm run build`. The generated static site will be in `dist/`.
